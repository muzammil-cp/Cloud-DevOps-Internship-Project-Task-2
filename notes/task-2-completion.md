## Objective

The objective of Task 2 is to provision, configure, secure, monitor, and document a basic AWS cloud infrastructure environment using AWS core services.

## AWS Services Implemented

The following AWS services and resources were used or configured during the project:

- AWS IAM
- Amazon VPC
- Public Subnet
- Internet Gateway
- Route Table
- Security Group
- Amazon EC2
- Ubuntu Server
- Nginx Web Server
- Amazon S3
- Amazon CloudWatch
- AWS Pricing Calculator

## Account Security

The AWS account security configuration includes:

- Root account MFA
- IAM administrative user
- IAM user MFA
- Appropriate permissions for the lab
- Protection of AWS credentials

Sensitive credentials and private keys are not included in the Git repository.
