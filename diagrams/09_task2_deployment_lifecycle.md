# 09 — Task 2 Deployment Lifecycle

## Objective

Show the complete workflow for the AWS Cloud Infrastructure Provisioning task.

## Lifecycle

1. Plan the requirements and select the AWS region.
2. Secure the account with root MFA and IAM.
3. Create the VPC and public/private subnets.
4. Configure route tables, Internet Gateway, Security Group, and SSH key.
5. Launch Ubuntu EC2.
6. Install and configure Nginx.
7. Create S3 storage and enable versioning.
8. Configure CloudWatch monitoring and the EC2 CPU alarm.
9. Complete screenshots, logs, architecture documentation, and cost estimation.

## Verification

All implementation steps should be verified against the actual AWS resources before final submission.
