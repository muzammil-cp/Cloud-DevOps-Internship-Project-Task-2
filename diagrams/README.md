The diagrams use the planned Task 2 resource names and network ranges from the project documentation. If the actual AWS deployment uses different values, update the corresponding Markdown file and image before final submission.

Never include AWS passwords, access keys, secret keys, MFA secrets, private SSH keys, or other credentials.
